# V4.76 upstream integration (draft)

Parents: fork `6e74d16fa652a9411329db670d88c1203bac5d2d` and upstream
`beb333cb1cda2a3e72b7c0c62d96c5ed971af1c2`. Both histories retained.

## Changes and preserved behavior

Adopts V4.60–V4.76: keyboard quote normalization, Artix support, infinite-desktop
wallpaper/panning fixes, new screenshot selection tool and both screenshot shortcuts.
Retains fork-main managed updater, fixed-SHA/fast-forward safeguards, AI island,
German keyboard defaults, Niri lock-recursion fix, background visualizer and profiles.
The missing `re` import is already common to both branches; no duplicate patch needed.
The upstream updater does not replace the managed fork updater.

Upstream removed the standalone Date module. This integration preserves its editor,
renderer and configuration entries so stored custom layouts lose no module. Island
date remains opt-in; upstream's idle date/time styling and explicit island-removal
flag are retained. AI activity behavior remains separate from idle date rendering.
Niri window screenshot requests now select a region instead of entering an unusable
window mode (upstream only populates window rectangles on Hyprland).

## Verification and merge gate

Python tests cover existing updater/German keyboard/Niri paths and five new cases:
legacy Date layout, explicit island remove/restore, quoted German keyboard values,
and Niri/Hyprland screenshot-mode dispatch. Screenshot transport is mocked.
Publication scan, Python entrypoint compilation, security suite and installer dry-run
are run locally. Exact-head CI is required for ShellCheck, Qt and both Nix profiles.
Local Qt launcher points at missing Qt5 runtime; ShellCheck and Nix are unavailable.

**Keep draft even if CI passes:** no live Quickshell/Wayland environment is available.
The existing Qt fixture does not exercise Snip's rendered cropping. Required before
merging: Print, Super+Shift+S and dashboard capture under Hyprland and Niri, horizontal
and vertical bars, cancel/reopen and save/copy; 100×100 logical selection must produce
the correct 160×160 PNG at Legion scale 1.6, then verify a mixed-scale second output.
Also visually check old/custom Date layouts and AI active/idle/disabled states.
No installation or deployment on user devices was performed.
